## 比較方法

## 判断

発動の早さと安定性が下がり、美沙リーダーの平均は57.6%まで低下。美沙・秋奈・白花の美沙リーダーは63.5%で引き続き強いが、編成自体の強さも含む値。非リーダーは47.8%でやや控えめ。効果を増減する追加修正は行わず、承認された4/8コストを採用する。CPU戦による相対評価であり、対人勝率の保証ではない。
