# 月田フクロウ 実装とCPU評価（2026-11-11）

採用仕様：初期VOL20%・手札5枚。リーダー「お静かに、患者様」。相手が観客カードを獲得すると、そのターンだけファンサービスと応援効果（無料使用を含む）を封印。応援の獲得と、楽曲・イベント・アイテム・リーダー固有処理は封印しない。ファンチップ獲得と交換はトリガーにしない。萌3人用は未行動化を残し、自動ファンサのみ飛ばす。

楽曲「執刀開始」「魔神改造」「人間卒業記念日」は標準のVOL/FANに加え、VOL・FANの両モードで相手のアイテム全枚とファンチップ全枚から均等抽選し1枚破壊。応援は対象外。くまは自身の破壊を防がない。

イベント「摘出カーテンコール」は本人2枚以上を含む6メモリー、使い切り。相手の応援をmin(6,所持数)枚奪う。0枚でも合法。CPUは通常3枚以上のとき使用し、最後の行動としては0枚でも使い切る。

## 測定条件

`scripts/balance-fukurou.mjs`。シード0xF01111。全17人の680通りの3人編成×3リーダー=2,040構成を各40ラウンド、構成順と組合せをシャッフルして対戦。各組合せは同一シードで先後を交換し2試合。81,600試合、163,200側の記録。各リーダー9,600試合、各非リーダーメンバー19,200試合。

偶数ラウンドは専用イベント3種、奇数ラウンドは専用2種＋共通1種。CPUは封印を認識し、フクロウ相手には手札が少なければ獲得前の応援ドローを優先する。人間の最善手、完全情報探索、特定大会の採用分布の再現ではない。

フクロウ不採用の2試合が2,000操作以内に終わらず。終局した81,598試合と区別する。フクロウを含む集計対象は全試合が終了した。未完2試合は既存キャラ同士の対戦で、フクロウの勝率の分母には含まれない。

|評価|試合数|勝率|
|---|---:|---:|
|フクロウがリーダー|9,600|45.90%|
|フクロウが一般メンバー|19,200|48.45%|

リーダー勝率は17人中16位、一般メンバーは12位。イベント採用時の使用率23.47%、使用1回あたり平均3.61枚の応援を奪取。破壊はフクロウ入り編成で平均約1.2枚/試合。封印はリーダー時に平均6.3ターン発動するが、既存CPUが行いたい全行動をそのまま妨げた回数ではない。

## 判断

現行CPU下では強すぎる兆候はなく、リーダーは弱め。初期VOL20%の遅さ、獲得前に応援を使われる余地、破壊対象がないと追加効果が空振りする点が重い。仁奈などの保有資源へ干渉する役割はあるが、あやめの券は獲得直後に使われると破壊の機会がない。汎用の必須枠という結果ではない。

仕様の自動弱体化・強化は行わない。強化を試すならまず初期VOL30%が比較しやすい。破壊枚数や封印範囲の増加は効果の性質を大きく変えるため、今回の実装には含めない。
