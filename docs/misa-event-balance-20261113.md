# 美沙イベント：常時3種ドリンク獲得の比較検証

検証日：2026-11-13。変更前の基準コミット：587626bb5341f7a99253d20f4529382ac1071836。

## 変更

本人3枚を含む合計7メモリー・ゲーム中1回・強制ターン終了を維持。青・赤・紫を各1枚必ず獲得し、劣勢時はさらに相手との点差と同じ一時ポイントを得る。取得したドリンクは今回の終了時から使用可能。通常行動には戻れない。

## 方法

同じ編成・先後・乱数シードで変更前後を対戦。全21キャラのうち美沙を除く20人から味方2人の全190組を使用し、各4条件・両席・リーダー3通りを検証。対戦相手には美沙を含めず、専用イベント3枚の条件と、専用2枚＋共通1枚の条件を混在させた。美沙側がリーダー1,520試合、非リーダー3,040試合を各バージョンで実行。

相性確認として4編成×全3リーダーを各160試合で実行。高勝率だった2編成と変化が大きかった白花リーダーを、それぞれ追加1,000試合で比較。合計18,960対戦、未決着なし。主検証の編成乱数初期値は0x1313af。追加検証は同じ初期値から別のシナリオ列を生成。

CPUは各バージョンの効果に合わせてイベント使用判断を行う。変更後は新規ドリンクのFAN2回分も終了時の勝利見込みに含める。既存CPUは観客点数を精密に探索せず、対人の温存・対策戦略を再現しない。

## 判断と限界

非リーダー時の採用価値は改善。リーダー平均61.7%と、美沙・秋奈・白花の美沙リーダー67.3%は強めで、過剰ではないと断定できない。現状は上位候補・要観察。メモリー軽減やターン終了削除の追加強化は行わない。対戦相手のイベント対策、イベント構成の最適化、人間の温存によって結果は変わる。特定の固定編成は変更前から高勝率であり、今回のイベントだけを原因としない。
